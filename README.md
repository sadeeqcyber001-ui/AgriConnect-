# AgriConnect

A website connecting farmers to buyers and helping reduce food waste in Nigeria.

## Why AgriConnect?

Much of the food grown in Nigeria is lost before it reaches a buyer. AgriConnect gives farmers a direct way to reach buyers, so produce gets sold instead of wasted.

## Features

- Connects farmers directly with buyers
- Helps reduce food waste

## Tech Stack

- HTML
- CSS
- JavaScript

## Getting Started

1. Clone the repo: `git clone https://github.com/sadeeqcyber001-ui/AgriConnect.git`
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Structure

- `index.html` – page structure
- `script.js` – site behavior
- `style.css` – styling
